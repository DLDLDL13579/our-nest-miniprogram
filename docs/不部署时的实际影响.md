# 不部署云函数时，五个玩法各自会怎样（2026-11-03 逐项核对）

> **为什么写这个**：一直说"要部署"，但没说清**每个玩法具体差在哪**。
> 这份清单按玩法列，方便判断"能不能先玩起来"。

## 大话骰

| 功能 | 不部署的表现 | 严重程度 |
|---|---|---|
| **不斋改斋减半** | ✓ **已生效**（共享模块）| — |
| **叫骰选项排序** | ✓ 已生效 | — |
| **起叫公式** | ✓ 已生效 | — |
| **围骰/全围分级** | ✗ **算错**：五颗全一样本应 +2，实际不 +2 | **高**（判错输赢）|

**结论**：能玩，但「豹子」那一档的算术会错。**玩家会觉得 App 算错了。**

## 比大小

| 功能 | 不部署的表现 | 严重程度 |
|---|---|---|
| **牌型名显示** | ✓ **已生效**（前端补算）| — |
| **排序（按牌型）** | ✓ 已生效（云端 `rankPlayers` 一直有）| — |
| **单骰重摇** | ✗ 按钮**已隐藏**（能力探测），功能不可用 | **中**（少一个玩法细节）|

**结论**：**能完整玩**，只是少「重摇」这一个操作。

## 谁是卧底

| 功能 | 不部署的表现 | 严重程度 |
|---|---|---|
| 投票进度（`iVoted`）| ✗ 前端不知道谁投了，可能有等待感 | **低** |
| 平票重投 | ✓ 一直有 | — |

**结论**：能玩。

## 梦幻金花

| 功能 | 不部署的表现 | 严重程度 |
|---|---|---|
| 全部功能 | ✓ 不受影响（没有待部署改动）| — |

**结论**：**完全能玩**。

## 命运转盘

| 功能 | 不部署的表现 | 严重程度 |
|---|---|---|
| **抽题去重** | ✗ 会重复抽到同一张（一局平均 1.65 次）| **低**（只是重复）|
| 其余 | ✓ 不受影响 | — |

**结论**：能玩，偶尔「刚才说过了」。

## 汇总

| 严重程度 | 玩法 | 表现 |
|---|---|---|
| **高** | 大话骰 | 豹子算错 → 判错输赢 |
| 中 | 比大小 | 少「重摇」按钮（已隐藏，不会点错）|
| 低 | 转盘 | 偶尔重复抽题 |
| 低 | 卧底 | 看不到投票进度 |
| — | 金花 | 无影响 |

**所以「能不能先玩起来」的答案是：能 —— 除了大话骰的豹子会算错。**

⚠️ 而"豹子算错"这件事，**玩家不会说"云函数没部署"**，
他会说「**这游戏算错了吧**」或者干脆不玩了。
