# 素材来源与许可

> 上线时可能要证明"这些东西能商用"；换素材时要知道"这个文件哪来的、能不能动"。
> 所有素材**均可商用**，其中绝大多数是 CC0（不需要署名）。

## 一、音效 · 35 个 WAV（580 KB）

| 来源 | 许可 | 用在哪 |
|---|---|---|
| **Kenney — Casino Audio** | CC0 | 骰子、筹码、牌的大部分 |
| **Kenney — Impact Sounds** | CC0 | 碰杯（glassClink）、重击 |
| 自合成（`scripts/gen-audio.py`） | 自有 | 摇盅、扣盅、揭晓、倒计时、连击 |

具体映射见 `scripts/import-audio.py` 的 `MAP`（哪个成品来自哪个源文件）。

⚠️ 合成音和真实录音**必须过同一套空间处理**（`spatialize`），
否则一局里两种音色并存会听出"不在一个房间"。这条在 AGENTS.md 里记过。

## 三、字体

**Bebas Neue**（`miniprogram/utils/fonts.js`，base64 内联）

- 许可：**SIL Open Font License 1.1**（可商用、可嵌入）
- 来源：Google Fonts（经 jsdelivr 的 `@fontsource/bebas-neue` 取 woff2）
- 只含 Latin 子集 13.7KB，**没有中文字形** —— 中文回退系统字体

## 四、图标

**42 个内联 SVG**（`miniprogram/utils/iconSet.js`）

- 自制（手写 path），无外部依赖
- 为什么不用 emoji：跨机型不一致（iOS 彩色 / Android 黑白）、颜色不可控、基线不齐

## 五、必须记住的两条

1. **不要引入 WebP 图片**。小程序 image 对 WebP 的支持依赖基础库/系统版本，
   万一不显示就是"整张图消失"，而 PNG 无条件支持。这个项目已经因此放弃过
   一次体积优化（WebP 同质量只要 41 KB）。
2. **素材要能被断言检查到数量**。`card/back.png` 曾躺在包里从没被引用
   （牌背是 CSS 画的）—— 现在 ③d-2 会数目录里的文件个数。
