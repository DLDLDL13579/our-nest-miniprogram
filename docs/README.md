## 一条约定

**这些文档里提到的具体数字（测试数、体积、版本）随时可能过时。**
需要当前值时，跑：

```bash
bash scripts/test-all.sh | grep -c '✓'    # 测试数
python3 scripts/quality-score.py           # 质量分
python3 scripts/size.py                    # 包体积
```
