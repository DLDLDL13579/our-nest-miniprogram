## 二、反馈：让每一次点击都有回应

- **9 个可点击操作点了完全没声音** → 补上（含「再来一局」这个唯一的重操作）
- **大厅的「开桌」和「进房」也没声音** → 补上（这两个是最重要的操作）
- 现在 **39 个可点击操作全部有声音反馈**（`toggleMute` 例外：静音开关本身不该响）
- **进房卡住 5 秒后换一句话**：从「马上就好」变成「还在进，别急 / 网络有点慢」
  —— 不是慢的问题，是**不知道还在不在动**
- 超时/断网给中文提示（原来直接显示 `cloud.callFunction:fail timeout`）

## 三、玩法规则：让人能玩懂

**大话骰**补了三条以前默认"大家都懂"的：

- 从房主开始按座位叫
- **往上叫 = 数量加一，或数量不变点数更大**（带例子：三个四 → 四个四 或 三个五）
- 输了喝 1 杯（劈过翻倍 2 杯）

**谁是卧底**补了**平票怎么办**（第一次平票不淘汰、补一句再投；二次平票卧底赢）。

**比大小 / 金花**补了"什么时候出结果""从谁开始"。

**三组题卡 + 词库逐条读过了**，换了 3 条会得罪人/冷场的题：

- 「你朋友圈屏蔽过谁」（被屏蔽的人可能就在座）
- 「让右手边的人翻你的相册」（翻到什么不由出题人决定）
- 「你小时候被家里人打过吗」（亲戚围坐时问了会冷场）

## 五、声音与动画

- **骰子逐颗落定分两档**：普通落定 220ms + 低音量，**只有最后一颗**走重音 ——
  五颗一样响的话，重音就被稀释了
- **环境底噪**：4 秒循环极低音量（关掉才知道刚才有）
- **音效预加载**：`sfx.init` 从来不存在（`sfx.init && sfx.init()` 是死代码），真补上了
- **开盅结算的 stagger 有一半是死的**（模板没设 `--i`，所有行同时出现）
