## 值得抄的（没做，以及为什么）

| 它的做法 | 我的判断 |
|---|---|
| **今晚战况**（谁喝了几杯一目了然） | **不做**。五玩法的 `lastResult` 结构各不相同，硬凑必然算错，而**算错比不算更糟**（喝酒游戏里"你欠几杯"是较真的事）。已只记局数（今晚第 N 局）。 |
| **纯 CSS 画图标**（不用任何图片） | **不做**。我们的骰子/骰盅是离线真渲染的 PNG，这是"像真桌子"的关键；纯 CSS 会退回"网页感"。 |
| **规避酒杯酒瓶意象** | **不跟**。它是为了过审，但牺牲了"酒桌"的辨识度。我们用骰盅 + 牌桌 + 暖光，更像真桌子。 |
| **「我好了，退出本轮」** | **已有**（离开房间 + 观战）。 |
| **惩罚题库分档**（温和/标准/劲爆 190 条） | **已有等价物**：4 个场合 × 40 条，按「场合」分而不是「尺度」——同事聚餐和长辈在场需要**不同的题**，不是同一套调辣度。 |
| **24 点 / 抽扑克 / 文字翻牌** | **不做**。前者是纯数学游戏（手机不提供服务不了的体验），后两个已在「梦幻金花」和「命运转盘」里覆盖。 |

## 一条产品判断

竞品里最值得学的**不是玩法**，是**产品化程度**：
合规提示、战况面板、"不强迫参与"的退出、题库分档 —— 这些让产品看起来"能上架"。

我们的优势在**单局体验的深度**（骰盅流程、牌桌三张牌的分工、回合超时、掉线标记），
而不在功能数量。
