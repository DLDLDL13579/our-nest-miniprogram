## 七、牌面分辨率：3 倍屏略软，但**决定不提**

**现状**：牌面图 140×196，金花里显示 136rpx（= 68pt）。
在 3 倍屏上需要 204 像素，而图只有 140 —— **等效 0.69 倍**，略软。

**算过提分辨率的账**（2026-11-03）：

| 方案 | 体积 | 是否可行 |
|---|---|---|
| 提到 2 倍（280×392） | 206 → **825 KB**（+619） | **超限**（1680 + 619 = 2299 > 2048）|
| 提到 1.5 倍（210×294） | +258 KB → 1938 KB | 可行，但只是**插值放大**，不增加真细节 |
| 保持现状 | 206 KB | ✓ |

**决定：保持现状。**

理由：1.5 倍是"用 258KB 换一点抗锯齿"，而**真细节需要更高分辨率的原始素材**。
仓库里没有 Kenney 牌的源 SVG（当初只取了渲染好的 PNG）。

**如果以后真觉得糊**，正确的做法是**重新找源素材**（Kenney Boardgame Pack 的 SVG 或 2x PNG），
而不是拿现有图插值放大 —— 后者是被 `docs/音效时长对照.md` 里那条
「换素材要重新算派生值」反过来的同一个道理：**放大不是换源**。

⚠️ 顺带：**这个"略软"在渲染图上看不出来**（渲染器是 1:1 出图）。
所以它是"真机才能察觉"的那一类 —— 和声音好不好听、动画跟不跟手一样，
**我只能指出它可能软，没法证明它看起来能不能接受。**

## 八、头像 8 色对色盲不友好 —— 但**不改**，因为座位号已经解决识别

**算了一遍**（红绿色盲模拟后按感知亮度排序）：

    红 0.401   黄 0.509   黄绿 0.397   绿 0.279
    青 0.296   蓝 0.219   紫  0.293    品红 0.413

**问题**：`红(0.401) ≈ 黄绿(0.397)`、`绿(0.279) ≈ 紫(0.293) ≈ 青(0.296)` ——
红绿色盲（男性约 8%）在这三对之间会混。

### 为什么决定不改

**每个头像旁边都有大号座位号 1~8**。色盲用户靠**数字**识别自己和别人，
颜色只是"扫一眼找到我"的辅助。

而"拉大亮度差"试了三版都失败：

| 方案 | 最小相邻亮度差 |
|---|---|
| 色相均匀 + 亮度阶梯（HLS 的 L） | 0.020 |
| 亮度主导（HLS 的 L） | 0.009 |

**根因**：`colorsys.hls_to_rgb` 里的 `L` 不是**感知亮度** ——
黄色和蓝色取同一个 `L`，感知亮度能差 3 倍。
要真正拉开，得在 LAB 空间里按目标亮度反解色相，或者干脆用灰度。

**而收益很小**：识别已经有数字兜底；而灰度会让 8 个头像看起来很沉闷。

⚠️ 这不是"没想到"，是**权衡后选择不做** —— 记在这里，免得下次重新算一遍。

## 九、「被罚」只有声音+震动，没有视觉动画 —— 试过，风险大于收益

**现状**（`feedback.js` 的 `penalized`）：

    animMs: 360, sfx: 'failDrop', sfx2: 'glassClink'(+260ms), haptic: 'long', vol: 1

**声音是两声**（下坠 + 碰杯）、**震动是 long** —— 这两层都很到位。
而 `animMs: 360` 这个数字**没有任何视觉在用**（模板里没有对应的 class）。

### 想加"落下 + 回弹"，但有两个坑

**坑一：轮询会让 CSS animation 反复重播。**
AGENTS.md 记过：结算页每 1.5 秒 setData 一次，`wx:for` 会重建节点 →
CSS `animation` 每次重建都重播。金花发牌动画就是因此改用 `transition`。

**坑二：`transition` 也需要"值变化"才触发。**
而 `.loserbox` 的内容（`{{result.loserName}} 喝 1 杯`）在结算后是**不变的** ——
没有值变化，transition 不会跑。

**要让它跑一次，得在 `decorate` 里加一个"刚结算"的时间戳标记** ——
而那是给一个 360ms 的动画引入一个**跨 1.5 秒轮询都存在的状态**，
出错时的表现是"每 1.5 秒弹一下"——**比没有动画糟得多**。

### 所以不做

**"被罚"这件事的强度，主要靠声音和震动就够了** ——
失败音 + 260ms 后的碰杯音 + long 震动，而 `.loserbox` 是 44rpx 的大字
（专门为"隔着桌子能读"调过）。

**动画能让它更好，但代价是"可能每 1.5 秒闪一次"的风险。**

⚠️ 这不是"没想到"，是**权衡后选择不做**。如果以后真要加，
正确做法是"结算瞬间播一次音频 + 用一个只存在一次的标记"，而**不是靠 CSS 自己动**。
