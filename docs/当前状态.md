# 当前状态（v3.19.5）

## 一、现在能玩什么

| 玩法 | 人 | 一句话 |
|---|---|---|
| 大话骰 | 2~8 | 猜全场有几个几点，不信就开 |
| 比大小 | 2~8 | 一起摇一盅，**比牌型**（8 种，不是比总点数） |
| 谁是卧底 | 3~12 | 有一个人拿到的词和你不一样 |
| 梦幻金花 | 2~6 | 一张亮着、一张自己看、一张靠猜 |
| 命运转盘 | 1~8 | 转一下，真心话还是喝一杯 |

内容量：**题卡 200 条**（4 场合）、**卧底词 240 个**（3 类）。

## 二、这一阶段（v3.17 ~ v3.19）改了什么

### 规则（按调研查到的主流酒桌规则重写）

| 改动 | 之前 | 现在 |
|---|---|---|
| 比大小的胜负 | 比总点数 | **比扑克牌型**（散牌<一对<两对<三条<顺子<葫芦<四条<五条） |
| 单骰 | 只能认命 | **可以重摇**（最多 3 次，真实规则里有） |
| 五个全一样 | 都算 6 个 | **全围 7 个 / 围骰 6 个** |
| 起叫数量 | 一张手填的表（斋全部多 1） | **公式**：不斋 = 人数×1.5，斋 = 人数 |

### 声音

| 修的问题 | 数据 |
|---|---|
| 转盘停稳的「叮」在酒桌上完全听不见 | 穿透段差 **37.5 → 11.5 dB** |
| 骰子落桌太闷 | 15.6 → **-1.0 dB** |
| 开盅前的蓄力听不见 | 73.4 → **21.7 dB** |
| 转盘「转起来了」听不见 | 72.3 → **12.1 dB** |
| 关键音效音量被砍 10% | 0.9 → **1.0** |
| 转盘结果卡片出现时静音 | **按格分级**（免罚=惊喜 / 一起喝=最重 / 喝=罚 / 题目=翻牌） |

### 交互与体验

- 「再来一局」**一局接一局**（原来要点两下）
- 房间号输错**自动清空**（原来要手动删一位）
- 卧底投票**区分「你还没投」和「还差别人」**（原来两个数字不同分母，会误导）
- 等待时加**呼吸动画**（原来完全静止，分不清"在等"还是"卡了"）
- 结算页「谁喝一杯」从 16px **放大到 22px**（隔着桌子要看得清）

### 视觉

- 赢家名字加**金色扫光**
- 54 处动画里给关键的 4 处补了 GPU 加速
- 59 处硬编码颜色收敛成 CSS 变量（视觉零变化）

## 五、还没做的（以及为什么）

| 项 | 为什么没做 |
|---|---|
| 投降 / 反弹 / 开多家 | 酒桌上是口头行为，App 代劳反而慢 |
| 比大小的「同花」 | 骰子没有颜色区分，调研也说通常不玩 |
| 音频降采样省体积 | **实际余量 459KB，不需要**（之前按 du 算成 220KB 是错的） |
| 观战页下半屏空白 | 观战是一局就结束的临时状态，硬填内容会跟主界面抢注意力 |
