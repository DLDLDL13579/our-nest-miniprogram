# 用户隐私保护指引 · 填写内容

> 位置：微信公众平台 → 设置 → 基本设置 → **用户隐私保护指引**
>
> **为什么必须填**：不填的话，敏感 API 会被直接拒绝。
> 本项目就踩过：`wx.setClipboardData` 报
> `api scope is not declared in the privacy agreement`，
> 房间号的"复制"功能因此整块下线。

---

## 一、本小程序实际用到什么（2026-10-30 核对）

扫了全部 `miniprogram/**/*.js` 里的 `wx.*` 调用，**涉及隐私相关 API 的只有两个**：

| API | 用途 | 是否敏感 |
|---|---|---|
| `wx.getStorageSync` / `wx.setStorageSync` | 存昵称、音效开关、错误日志 | **否**（本机存储，不上传） |
| ~~`wx.setClipboardData`~~ | ~~复制房间号~~ | 已在 3.10.144 **移除**（隐私限制绕不过去，改成引导转发） |

**没有用到**：位置、通讯录、相册、摄像头、麦克风、剪贴板（现无）、微信昵称头像（没有 `getUserProfile`）。

**结论：这个小程序的隐私面非常小。** 用户信息只有两个来源：

1. **用户自己输入的昵称**（可选，不填就用"房主/玩家N"）——存本机 + 房间记录里
2. **微信分配的 openid**（云开发自动给，不包含任何个人信息）

## 二、按这个填（照抄即可）

### 开发者处理的信息

勾选/填写：

```
收集你的昵称
```

用途说明：

```
用于在多人游戏房间里显示你的名字，让同桌的人知道是谁。
不填也能玩（会用「玩家1」这样的默认名）。
```

### 是否需要提供以下信息才能使用

**不需要**——所有功能在不提供昵称的情况下都能使用。

### 信息存储与删除

```
昵称存在你自己的手机上（localStorage）和房间记录里；
房间 2 小时后自动过期，24 小时内被清理。清理本机缓存可随时删除。
```

## 三、如果后台要求逐项声明 API

按这张表填（**只填实际用到的**）：

| API 名称 | 声明用途 | 是否必须填 |
|---|---|---|
| `wx.getStorage` / `wx.setStorage` | 保存昵称、音效开关、错误日志等本机设置 | 是 |
| （其余全部） | —— | **不填** |

**不要多勾**。多声明一个权限，审核时就要多解释一次"你为什么需要它"。

---

## 四、填完怎么验证

1. 填完提交后，**等几分钟**（后台生效有延迟）
2. 重新扫码打开小程序
3. 进任意房间，点房间号卡片
4. **应该弹出「把房间号发给朋友」的引导提示**（而不是"复制没成功"的错误弹窗）

如果还报 `api scope is not declared`，说明：
- 后台没保存成功，或
- 生效还没到（等 10 分钟再试），或
- **这个 API 已经不在代码里了**（本项目的情况）——
  那么报错来自别的地方，去看「我的 → 查看诊断信息」。
