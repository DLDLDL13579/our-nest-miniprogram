## 性能实测（2026-10-30）

| 指标 | 值 | 说明 |
|---|---|---|
| 大厅渲染 | **21ms** | 纯本地（注册表 + localStorage），**0 网络请求** |
| 建房（第 1 次，冷启动） | 1324ms | 云函数实例首次拉起 |
| 建房（第 2~3 次，热） | 726~1070ms | 预热生效后 |
| 摇骰 → 揭盅 | ~260ms | |
| 揭盅 → 结算 | ~1300ms | 留时间看骰子 |

**三层优化**：
1. 大厅不依赖网络（玩法卡从本地注册表读）
2. `warmup()` 在大厅/房间页 onLoad 时发 ping 叫醒云函数
3. 所有耗时操作都有 loading 遮罩（`setLoading` 带 5s/15s 双兜底）
