## 二、别踩的坑（每条都付过代价）

### 1. mock 是"假数据"，它会骗你

`scripts/ui-render/mock/` 决定了离线截图能信多少。

- **造假字段** → 截图正常、真机空白（`byText` 藏了好几轮）
- **缺默认值** → 破图（`cupSrc` 补了四次）
- **放错层级** → 默认值失效（页面级 vs `room.` 级）
- **状态名拼错** → 静默渲染成大厅（我白看好几张"金花截图"）

规则写在 `scripts/ui-render/README.md`。**加状态前先读它。**

### 2. 「看起来不对」先量，别靠眼睛

我曾经为了"弹层右侧溢出 25%"追了三轮，怀疑过 `app.wxss` 没加载、
父级 transform 让 fixed 退化、box-sizing 失效 —— **全不是**。
最后量像素：内容右边界 749 / 图片宽 750，**根本没溢出**。

那个"截断"是两个并排按钮里第二个正常被裁掉一部分。

### 3. 判据不能依赖"代码长什么样"

同一条断言（mock 字段形状）写了三版都失败，因为都在**读源码猜形状**：

- 全局搜 `field: ['` → `players` 被误伤
- 加 `.map(` 排除 → 换行后正则断掉
- 配平取数组 → 空数组被判成字符串数组

第四版换思路：**真的 require mock，跑每个状态看运行时类型** —— 一次就对。

> **"判据不能依赖代码写法"的正确解法不是放弃判据，而是换一个能直接观察到事实的判据。**

### 4. 拆包/挪目录后，要扫的不只是 import

2026-10-28 拆分包时，美术资源移到 `game/images/`，但**三个脚本的默认路径没跟着改**：

- `gen-share-cover.py` 的 `IMG`
- `render-cup.py` / `render-dice.py` 的 `--out`

重跑这些脚本会把产物写进**不存在的目录**，且不报错。**藏了 8 天才发现**。
现在有断言（`test-contract.js` ④·路径）盯着。

### 5. 功能改了，解释它的"文案"也要跟着扫

同一类错犯过四次：

- 斋做完了 → 规则列表里没提斋
- 围骰做完了 → 结算页说不清 +1
- 暗牌改「取最优」→ 提示还写"有机会"
- **剪贴板删了 → 三处还在说"复制"**

现在有断言查「界面承诺的动作，代码里有没有对应能力」。

### 6. 声画的三个层次（用户报"声音不对"时按顺序查）

| 层 | 典型问题 | 怎么查 |
|---|---|---|
| 时机 | 声音早于画面 | `setData` 是异步的 —— 音效要放进回调 |
| 间隔 | 长音效没播完就起下一个 | `python3 scripts/check-audio-overlap.py` |
| 响度 | 提示音比高潮音还响 | `python3 scripts/audio-levels.py` |

三次都是靠**量**出来的，凭耳朵只能说"乱"。

## 三、还差什么（都需要人，不是代码）

| 差距 | 为什么代码解决不了 |
|---|---|
| **没上架 → 生成不了小程序码** | 微信规定未发布不能生成永久码，别人扫不了 |
| **服务类目未定** | 选错**不可改**，必须产品所有者拍板 |
| **隐私指引未填** | 剪贴板功能就是因此被禁 |
| **真机多人未验证** | 需要两台手机、两个人 |
| **"好不好玩"未验证** | 需要一桌真人 |
| 美术素材仍是公共库 | 52 张牌是 CC0 蚀刻风（已明显好于原来的像素牌），但仍非定制 |
