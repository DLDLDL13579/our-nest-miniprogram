## 二、别踩的坑（每条都付过代价）

### 1. mock 是"假数据"，它会骗你

`scripts/ui-render/mock/` 决定了离线截图能信多少。

- **造假字段** → 截图正常、真机空白（`byText` 藏了好几轮）
- **缺默认值** → 破图（`cupSrc` 补了四次）
- **放错层级** → 默认值失效（页面级 vs `room.` 级）
- **状态名拼错** → 静默渲染成大厅（我白看好几张"金花截图"）

规则写在 `scripts/ui-render/README.md`。**加状态前先读它。**

### 2. 「看起来不对」先量，别靠眼睛

我曾经为了"弹层右侧溢出 25%"追了三轮，怀疑过 `app.wxss` 没加载、
父级 transform 让 fixed 退化、box-sizing 失效 —— **全不是**。
最后量像素：内容右边界 749 / 图片宽 750，**根本没溢出**。

那个"截断"是两个并排按钮里第二个正常被裁掉一部分。

### 3. 判据不能依赖"代码长什么样"

同一条断言（mock 字段形状）写了三版都失败，因为都在**读源码猜形状**：

- 全局搜 `field: ['` → `players` 被误伤
- 加 `.map(` 排除 → 换行后正则断掉
- 配平取数组 → 空数组被判成字符串数组

第四版换思路：**真的 require mock，跑每个状态看运行时类型** —— 一次就对。

> **"判据不能依赖代码写法"的正确解法不是放弃判据，而是换一个能直接观察到事实的判据。**

### 4. 拆包/挪目录后，要扫的不只是 import

2026-10-28 拆分包时，美术资源移到 `game/images/`，但**三个脚本的默认路径没跟着改**：

- `gen-share-cover.py` 的 `IMG`
- `render-cup.py` / `render-dice.py` 的 `--out`

重跑这些脚本会把产物写进**不存在的目录**，且不报错。**藏了 8 天才发现**。
现在有断言（`test-contract.js` ④·路径）盯着。

### 5. 功能改了，解释它的"文案"也要跟着扫

同一类错犯过四次：

- 斋做完了 → 规则列表里没提斋
- 围骰做完了 → 结算页说不清 +1
- 暗牌改「取最优」→ 提示还写"有机会"
- **剪贴板删了 → 三处还在说"复制"**

现在有断言查「界面承诺的动作，代码里有没有对应能力」。

### 6. 声画的三个层次（用户报"声音不对"时按顺序查）

| 层 | 典型问题 | 怎么查 |
|---|---|---|
| 时机 | 声音早于画面 | `setData` 是异步的 —— 音效要放进回调 |
| 间隔 | 长音效没播完就起下一个 | `python3 scripts/check-audio-overlap.py` |
| 响度 | 提示音比高潮音还响 | `python3 scripts/audio-levels.py` |

三次都是靠**量**出来的，凭耳朵只能说"乱"。

## 三·五、一个没查出来的已知问题

**`test-all.sh` 偶发 `SyntaxError: Invalid or unexpected token`（已出现 4 次）**

| 项 | 情况 |
|---|---|
| 现象 | 报错指向 `test-all.sh:2`，即 shell 脚本被当成 JS 解析 |
| 频率 | 4 次，**每次都重跑即过** |
| 共同点 | 都发生在"同一条命令里既改文件又跑测试"时 |

**已排除**：共享 `/tmp` 文件冲突、有脚本 `node *.sh` 调用、变量展开问题、
并发读写（模拟边同步边测试未复现）、稳定性（连跑 8 次全绿）。

**已加防御**：脚本开头判 `BASH_VERSION`，被非 bash 执行时打印
「✗ test-all.sh 被非 bash 解释器执行了（当前: \$0）」并 exit 2，
而不是只扔一行 SyntaxError。

**下次出现时先看那句提示** —— 它会说明是谁在用什么解释器跑它。
如果提示没出现（说明确实是用 bash 跑的），那问题在更深的地方。

**它至今没有影响过任何一次交付**（每次重跑都绿，且部署前必跑）。

## 六、探针/自动化的坑（2026-10-30 补）

**这些坑的共同点：探针不会报错，只会返回"看起来正常的空结果"。**

| 坑 | 现象 | 正确做法 |
|---|---|---|
| **tabBar 页要用 `switchTab`** | `mini.navigateTo('/pages/me/me')` **静默失败**，`currentPage().path` 还是上一页 → 之后所有 `$('.xxx')` 都返回 0 个 | 用 `mini.switchTab('/pages/me/me')` |
| **选择器写错** | `$$('.chipbar .chip')` 返回 0，看起来像"产品没有这个元素" | 先在 wxml 里 grep 真实类名；断言 ④·d 会检查 |
| **读错 storage key** | `wx.getStorageSync('muted')` 返回 `''`，看起来像"没存进去" | 真实 key 是 `gameMute`；**先 grep 常量** |
| **固定 sleep 赌时间** | `sleep(3200)` 后读状态，偶发读到中间态 | **轮询到条件成立**，不要赌固定时长 |
| **`_dead` 这类实例属性** | `page.data()._dead` 是 `undefined`，看起来像"页面已死" | 实例属性不在 `data` 里，`data()` 读不到 |

> **判据：探针报"0 个元素 / undefined / 空字符串"时，先怀疑探针，再怀疑产品。**
> 我在这上面误判了 10 次。
