# 音效时长 ↔ 代码里的等待（换素材时必看）

> **为什么有这份文档**：2026-11-02 把音效换成真实录音后，出了三个 bug ——
> 全都是「某个数字其实是**某个素材时长的副本**」：
>
> | 症状 | 那个数字 | 它真正的含义 |
> |---|---|---|
> | 揭开盅后静默近 1 秒 | `1080` / `1750` | 「revealHit 长 1.05 秒」 |
> | 逐颗落定只剩最后一声 | `POOL_SIZE` 里没 diceSettle | 「合成版只有 60ms 有能量」 |
> | 扣盅从「沉」变「脆」 | `sharpen_transient` | 「合成音起音软」 |
>
> 这三个数字**看起来都像业务常量**，实际全是素材的派生值。

## 一、当前音效时长（2026-11-02，真实录音为主）

| 音效 | 时长 | 用途 |
|---|---|---|
| `cup-shake` | 1050ms | 摇盅 |
| `cup-slam` | 168ms | 扣盅（全场最重） |
| `reveal-hit` | 123ms | 揭盅「当」 |
| `dice-settle` | 300ms | 逐颗落定 |
| `impact-low` | 211ms | 低频冲击层 |
| `confetti` | 1200ms | 撒花（赢） |
| `wheel-stop` | 740ms | 转盘停稳 |

## 二、代码里「等它播完」的地方

| 位置 | 等待 | 等的是什么 | 怎么算的 |
|---|---|---|---|
| `doRoll` 摇盅 | 1050ms | 摇盅动画 | = `cup-shake` 时长 |
| `doRoll` 扣盅 | 400ms | 清 `cupCls` | = `cupSlam` 的 `animMs`(380) + 20 |
| 开盅 ① | 380ms | 抬盅动画 | `cupOpen.animMs`(340) + 40 |
| 开盅 ② | 440ms | `impactLow` | 揭开后的低频补充 |
| 开盅 ③ | 640ms | `revealHit` | = ② + 200 |
| 开盅 ④ | **820ms** | 胜负音 | 640 + **123**(reveal-hit) + 57 |
| 开盅 ⑤ | **2080ms** | `gulp` | 820 + **1200**(confetti) + 60 |
| 比大小揭盅 | **820ms** | 胜负音 | 同上 |

**加粗的是 2026-11-02 重算过的**（原来是 1080 / 2300 / 1750）。

## 三、换音效素材时的检查清单

1. **改完素材先量时长**：
   ```bash
   python3 -c "import wave; [print(f'{f}: {wave.open(\"miniprogram/game/audio/{f}.wav\").getnframes()/wave.open(\"miniprogram/game/audio/{f}.wav\").getframerate()*1000:.0f}ms') for f in ['reveal-hit','cup-slam']]"
   ```

2. **搜代码里有没有「等它播完」的定时器**：
   ```bash
   grep -nE "\}, [0-9]{3,5}\)\)" miniprogram/game/room/room.js
   ```

3. **重算所有 `A + 时长 + 余量` 的式子**，把注释里那句「XXX 播完之后」也改掉。

4. **重新检查音效池**：`间隔 < 时长` 的必须有池（见 `sfx.js` 的 `POOL_SIZE`）。

5. **跑三个工具**：
   - `python3 scripts/audio-levels.py`（层级 + 时长判据）
   - `python3 scripts/check-audio-overlap.py`（重叠）
   - `python3 scripts/audio-pierce.py`（外放穿透）

## 四、还有哪些数字是「素材的副本」

| 数字 | 在哪 | 依赖什么 |
|---|---|---|
| `EXPECT_MS` | `audio-levels.py` | 每个音效的实际时长 |
| `POOL_SIZE` | `sfx.js` | 音效时长 vs 播放间隔 |
| `TARGET_50MS` | `audio-levels.py` | 素材的起音能量（合成音和真实录音差很远） |
| `LOUDNESS_FIX` | `gen-audio.py` | 只对**合成音**有效，真实录音不经过它 |

⚠️ 最后一条特别容易搞混：`LOUDNESS_FIX` 里还有 `cup-slam: -11.6` /
`reveal-hit: -14.2`，但这两个音效**已经不经过 gen-audio.py 了** ——
那些值现在是死配置。
