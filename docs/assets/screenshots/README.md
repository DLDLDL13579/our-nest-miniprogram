# 真机截图（2026-10-30）

**这些不是离线渲染，是 automator 拉起真实微信运行时截的。**

和 `outputs/ui/` 下的离线渲染图的区别：

| | 离线渲染 | 真机截图 |
|---|---|---|
| 来源 | wxml + wxss 自己拼 HTML | 真实小程序运行时 |
| 导航栏/tabBar | 占位 | **真实** |
| 横向滚动 | 表现不同 | **真实** |
| 字体/行高 | 近似 | **真实** |
| 可信度 | 只能证明布局 | **用户看到什么就是什么** |

## 为什么存档

离线渲染骗过我几次（最典型：叫骰按钮一行显示 5.5 个，
第六个被切一半 —— 离线图看不出来，真机图一眼就看到）。
以后改界面，**以这里的图为准**。

## 怎么重新生成

```bash
node .tooling/probe.js --file /tmp/v-shots.js    # 需要 IDE 的自动化端口
```
