# 排查：开不了房间

> 我这边（代码、配置、部署、云环境）全部核对过了，都是对的。
> 所以问题大概率在"跑的是哪一版"或"运行时某一层"。按下面顺序走，每一步都能排除一类。

---

## 第 0 步：先确认你打开的是哪一版

去「我的」页往下滑，找到「关于」→ 看版本号。

- **不是 3.10.73** → 你扫的是缓存里的旧版。**把小程序从"最近使用"里删掉，重新扫码。**
- **是 3.10.73** → 往下走第 1 步。

> 这一步能排除掉一半的情况。微信会对已打开过的小程序做缓存，
> 尤其"预览版"——扫码不一定拉到最新的。

---

## 第 1 步：看屏幕上写了什么

点任意一个玩法卡。三种结果：

| 你看到 | 说明 | 下一步 |
|---|---|---|
| **进到房间了**（看见房间号） | 已经好了 | 告诉我，我把"金花计入战况"补回来 |
| **屏幕上有一行红字**（如"房间满了""超时"） | 就是它 | **把红字截图发我**，那是云函数返回的原话 |
| **什么都没有，或者一直转** | 见第 2 步 | |

---

## 第 2 步：去「我的」页看红字错误

「我的」页往下滑，如果有「最近 N 条错误」，下面会直接列出原始错误文本。

**把那两行截图发我。** 里面会是类似：

```
room/create：cloud.callFunction:fail timeout
room/create：cloud.callFunction:fail -404011 ...
```

- `timeout` → 云函数超时（冷启动 / 执行太久）
- `-404011` / `not found` → 云函数没部署到你这个环境
- `collection not exists` → 数据库集合没了
- 其他 → 把原文发我

---

## 第 3 步：如果复制不了

「复制诊断信息」现在如果失败会弹窗告诉你原因。

**并且**：页面上已经直接印着错误原文了，**截图就够，不用复制**。
