# 交付说明（v3.36.6）

这份是**给你看的**，不是给未来的我或下一个人看的。
所以它只回答三个问题：能玩什么、现在什么状态、还差什么。

---

## 一、能玩什么

五个玩法，都是酒桌上真在玩的：

| 玩法 | 人 | 一件事 |
|---|---|---|
| 大话骰 | 2~8 | 猜全场有几个几点，不信就开 |
| 比大小 | 2~8 | 一起摇一盅，**比牌型**（散牌 < 一对 < … < 五条）|
| 谁是卧底 | 3~12 | 有一个人拿到的词和你不一样 |
| 梦幻金花 | 2~6 | 一张亮着、一张自己看、一张靠猜 |
| 命运转盘 | 1~8 | 转一下，真心话还是喝 1 杯 |

内容量：**题卡 200 条**（4 个场合）、**卧底词 120 对**。

## 三、还差什么

### ⚠️ 云函数没部署 —— 这是唯一一件"玩家会认为有 bug"的事

四个功能改在云端，**本地代码对了但线上还是旧版**：

| 功能 | 不部署的表现 |
|---|---|
| **豹子算错** | 五颗全同本该算 7 个，现在算 5 个 —— **赢的人变输** |
| **围骰分级** | 「四条」徽章不显示（模板读了 `handicapWin`，云端没返回）|
| **抽题去重** | 一晚上可能抽到重复的题 |
| **单骰重摇** | 按钮已隐藏（能力探测），规则里也标了「暂未开放」——**不会困惑，但用不了** |

**怎么部署**（两个办法，二选一）：

1. **你自己在开发者工具里做**：右键 `cloudfunctions/room` → 「上传并部署：云端安装依赖」
2. **让我做**：说一句「部署」，我跑 CLI，做完立刻关工具、确认 0 残留进程

**我需要你明确同意才做第 2 种** —— 因为 `cli cloud` 命令会拉起开发者工具，
而你早说过不要在你的电脑上开 GUI。

## 四、怎么自己验

```bash
bash scripts/test-all.sh          # 514 项，跑一遍约 90 秒
python3 scripts/quality-score.py  # 40/40
python3 scripts/size.py           # 包体积（用实际文件大小，不是 du）

node scripts/render-ui.js room --state liar8Mine   # 渲染单个状态
python3 scripts/contact-sheet.py                   # 61 个状态拼一张图
```

**这些都不需要开发者工具**，不会抢你的屏幕。
