## 一点六、可诊断性：「我的」页成了诊断面板

真机出了问题，我原来只能靠用户描述（"操作失败""有点卡"）。
现在「我的」页有三样东西可以**一键复制**：

| 入口 | 内容 | 什么时候用 |
|---|---|---|
| 错误记录 | 时间 / 云函数 / action / 原始错误串（最近 20 条） | 报"操作失败" |
| 诊断信息 | 版本 / 机型 / 系统 / 微信 / 基础库 / 屏幕 / 网络 / **上次启动耗时** | 报"卡""显示不对" |
| 内存警告 | `wx.onMemoryWarning` 触发时也进错误日志 | 报"玩久了变卡" |

**启动耗时**是这一组里最有用的：`onLaunch → onReady` 的差值，
反映"主包大小 + 首屏渲染"的变化（不是用户感知的全部，前面还有小程序启动阶段）。
拆分包前后这个数字应该明显不同 —— 而在此之前，"首屏多快"一直是个我答不上来的问题。

隐私口径：错误日志**只记技术信息**，不记昵称、房间号、词/题。

## 一点五、新增的"机制是否真的在跑"类断言

有些东西**代码看起来有、实际可能没在跑**，而且失效时不报错，只会悄悄让体验变差。
这几轮补了四条专门验机制的：

| 脚本 | 验什么 | 失效的后果 |
|---|---|---|
| `test-pitch.js` | 音效抖动（20 次播放 20 种 playbackRate） | 一局里同一声音完全一样 = 打点机感 |
| `test-pool.js` | 音效池化（密集音效轮转实例） | 摇盅 22ms 一次的撞击互相掐断，哗啦变哒哒 |
| `test-room-changed.js` | 轮询去重（`countdownMs` **不**参与比较） | 每 1.5 秒都重绘一次，手机发烫 |
| `test-firsthint.js` | 首次引导只出现一次 | 每次都弹（骚扰）或永远不弹（等于没做） |
| `test-recent.js` | 最近玩过的排序 + 老数据兼容 | 常玩的玩法排不上来 |
| `test-me.js` | 「我的」页数字跟着更新 | 玩完回来还显示"今晚 0 局" |
| `test-toast.js` | toast 时长够读完（150ms/字） | "点了没反应"的一部分其实是提示已消失 |

## 一点七、真机反馈驱动的修复（2026-10-29）

用户给了 5 条反馈，**每一条都是我自己查不出来的**。它们有个共同病根：
**出错的时候没把信息交出来**。

| 用户说的 | 根因 | 状态 |
|---|---|---|
| 卡在「正在进入房间」 | 3.10.26 加的全屏遮罩，`doCreate` 从来没关 | 已修 + 15 秒兜底 |
| **所有游戏开不了房间** | 内容检查服务自身失败也返回 `pass:false`，建房被整个拦死 | 已修（昵称降级放行） |
| 声音有延迟 | 34 个音效只预加载 6 个 | 已修（13 个） |
| 复制不了 | `setClipboardData` 没有 `fail` | 已修 |
| 点了没反应 | 跳转静默失败 / 守卫静默 return | 已修 |

### 最重要的一条

**「所有游戏开不了房间」那个 bug，313 项断言一条都没抓到。**
因为它不在"代码逻辑对不对"的层面，而在"外部服务不可用时还能不能用"的层面。

修复是**分层降级**：昵称（低风险、不公开）在检查服务挂了时放行；
自定义题卡（会给全场看）仍然严格拦截。

### 由此补的四条断言

| 断言 | 管什么 |
|---|---|
| ④d | 拉起全屏遮罩必须有对应关闭 |
| ④e | 断网分档提示（重试中 / 已断开 / 已恢复） |
| ③n | 跳转 / 复制失败不能静默 |
| ③o | 音频实例必须挂 `onError` |
| ⑭ | 内容检查挂了建房仍能开（题卡仍拦） |

**这五类此前一条断言都没有** —— 因为断言全在查"成功路径对不对"。

### 一条方法论

写这五条断言时，**没有一条是一次写对的**：要么被注释骗（注释里提到同一个词）、
要么被同类代码骗（清零也是赋值、读取也算出现）、要么判据太宽。
**每次都是靠反向验证才发现**。

## 二、没有验证的（只有真机能回答）

| 项 | 为什么验不了 | 怎么验 |
|---|---|---|
| **首屏耗时** | 渲染器和开发版都不代表真机 | 手机上数秒数 |
| **base64 字体是否加载** | `wx.loadFontFace` 对 data URI 的支持依赖基础库 | 看数字是不是窄体 |

| **内容会不会冷场** | 需要真实酒桌 | 用一晚上看哪条题没人接 |

> ⚠️ 这六项里，**前两项如果失败，我今天做的两个优化就是白做**（分包音效、字体）。

## 三、已修的真问题（这两天）

按发现顺序，只列**会让人不想再玩**的那一类：

| 问题 | 后果 |
|---|---|
| 单人开卧底卡死在投票页 | 一个人试玩直接卡住 |
| 摇完还能再摇（骰子被重摇） | 结果不可信 |
| 重开一局卧底状态残留 | 第二局起点就是脏的 |
| 云函数超时显示英文 `fail timeout` | 用户只能反馈"操作失败" |

| 房主锁房后自己人也进不来 | （已避免：房内重进不受影响） |
| 题库 3 条会得罪人/冷场的题 | 一桌人尴尬一次 |
| 大话骰规则没说"输了喝几杯" | 桌上第一个问题答不上 |
| 大话骰规则没说"什么叫更大" | 那句"这个能叫吗"每次开局都要问 |
| 卧底规则没说平票怎么办 | 投票类必然撞上 |
