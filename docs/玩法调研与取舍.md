# 玩法调研与取舍（2026-10-30）

> 用户要求「不断调研网上已有游戏」但又强调「**重点不在新加游戏**」。
> 这份文档回答的是：**有哪些玩法被考虑过、为什么不做**。
>
> 加一个玩法容易，砍一个玩法很难 —— 而酒桌游戏最怕的不是玩法少，
> 是**玩家记不住规则**。所以先按判据筛，再动手（AGENTS.md 铁律②）。

## 判据（来自 AGENTS.md 铁律②，一字不改）

手机必须提供现实中难以替代的价值，至少满足一条：

1. 需要**秘密信息**（别人不能看见）
2. 需要**真随机且可验证**
3. 需要**大量内容库**
4. 需要**仲裁顺序 / 计时**
5. 需要**跨轮持久记录**

反之：**「现场能抛开手机玩的，不要写」**。

## 逐个判定

| 玩法 | 判据 | 结论 | 理由 |
|---|---|---|---|
| **十五二十** | 无需手机 | ✗ 不做 | 伸手就能玩，手机只是记分板 |
| **数字炸弹** | 勉强算"秘密" | ✗ 不做 | 现实里一人心里想个数字即可，手机没有增量 |
| **APT（公寓游戏）** | 无需手机 | ✗ 不做 | Rosé 带火的手势节奏游戏，靠手和嘴 |
| **猜拳类 / 石头剪刀布** | 无需手机 | ✗ 不做 | 同上 |
| **騙子酒館 Liar's Bar** | 秘密信息 ✓ | ✗ 不做 | 核心是"吹牛 + 质疑"，**与大话骰高度重复**；再加一个只是换皮 |
| **Photo Roulette（猜照片）** | 需要相册 | ✗ 不做 | 要读用户相册并上传 —— 隐私风险远大于收益 |
| **猜价格（Kashoo）** | 内容库 ✓ | ✗ 不做 | 题库要长期维护价格数据，且"猜价格"现场查手机就能玩 |
| **我有你没有** | 只满足"记录" | ✗ 不做 | 举 10 根手指就能记 —— 项目历史上写过服务端 + 前端 + 8 项测试后被否 |
| **"谁是卧底"** | 秘密信息 ✓ + 内容库 ✓ | ✓ 已做 | 两条都硬 |
| **大话骰 / 梦幻金花 / 比大小** | 真随机 ✓ + 秘密信息 ✓ | ✓ 已做 | 骰子和牌必须是"真的随机且没人能偷看" |
| **命运转盘（真心话大冒险）** | 内容库 ✓ + 仲裁 ✓ | ✓ 已做 | 200 条题卡 + 服务端抽题（确保全场看到同一张） |

## 结论

**现有 5 个玩法已经覆盖了"手机不可替代"的全部判据**，
而经典酒桌游戏的大多数恰恰属于"现场就能玩"——被铁律②挡在门外是对的。

**如果要继续加，先回答一个问题**：
新玩法满足哪一条判据，且**不和现有的 5 个在机制上重复**？

目前的空白只有两类，都不值得做：

- **纯社交类**（投票/提问）→ 手机不参与反而更好
- **动作/反应类**（抢答/手势）→ 手机的延迟会让游戏变得不公平

## 附：这轮顺带做的内容扩充

- 题卡 **160 → 200 条**（每场合 20 → 25 条），按收题三问新增，全库零重复
- 卧底词库 120 对（3 类 × 40），核对过"同类同量级"（苹果/梨 ✓，苹果/冰箱 ✗）

## 附二：酒桌游戏的「三条金律」（2026-10-30 找到的外部研究）

来源：[The 3 Golden Rules Of Designing Drinking Games](https://medium.com/@maxvwalbert/the-3-golden-rules-of-designing-drinking-games-4e60949d42e1)
（作者访谈 200 名大学生 + 3 年 A/B 测试得出的结论）。

### ① 玩家要能按自己的量喝 → **我们已做到，且更彻底**

原文洞察：酒桌游戏有**两个目标**（赢 + 喝），而 Beer Pong 这类把两件事绑死
（输的人必喝 10 杯）→ 轻喝的人被灌、重喝的人不过瘾。
它的推荐方案是"指派喝酒"机制（玩家给别人分派酒量）。

**我们的做法**：所有玩法都写「App 只管判输赢，喝多少你们定」——
**完全不插手酒量**，比原文方案更彻底。

### ② 强度曲线（climax）→ **这是真实的差距**

原文洞察：现代酒桌游戏（Kings Cup 模板）最大的失败是**没有高潮**——
低强度卡和高强度卡随机混在一起，曲线毫无章法，而玩家要的是"一个了不起的结尾"。

| 玩法 | 有没有强度递增 |
|---|---|
| 大话骰 | ✅ 越叫越大、越高危 |
| 梦幻金花 | ✅ 人越来越少 |
| 谁是卧底 | ✅ 人越来越少 |
| **比大小** | ❌ 摇一次就比 |
| **命运转盘** | ❌ 转一次出一个词 |

**待定**：比大小/转盘的"多局累积"（三局两胜之类）会**改变玩法本身**，
属于"新加机制"而不是"优化"，**没有用户明确要求前不做**。

### ③ 规则要简单到醉汉能懂 → **部分偏长**

原文：*"用一条推文能说清规则，否则就太长"*；**限制文字、能演不靠说**。
它的榜首例子（Picolo）规则是：「点手机，照屏幕做就行」。

| 玩法 | 规则条数 |
|---|---|
| 大话骰 | ⚠️ 9 条（含斋/围骰/劈的细分支，偏长） |
| 其他四个 | 7 条左右 |

**判断**：大话骰的 9 条是**规则完整性的必然代价**（斋和围骰不加就是错的），
但"看规则"是用户主动打开的弹层——他点开就是想看全，折叠反而多余。
**所以不改成折叠式。**

### 这条调研对我们意味着什么

**①做得对、③是必然代价、②是真实差距但改法会动玩法。**
结论：现有设计在"酒桌游戏"这个品类里是站得住的，
剩下的差距都属于"要吗冒险改玩法、要吗接受"的取舍。
