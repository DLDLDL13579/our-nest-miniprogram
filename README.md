# 酒桌 · 微信小程序

线下酒桌用的多人小游戏。**一个人开一桌拿到 3 位房间号，其他人输号进来，各自看自己的手机。**

5 个玩法：大话骰 / 比大小 / 谁是卧底 / 梦幻金花 / 命运转盘。

> 2026-10-27 之前这是一个情侣记录 App（「我们的小窝」，文档在 `docs/archive/`）——
> 那天整站转向酒桌游戏，情侣功能与它们的云函数全部删除。**不要试图恢复。**

## 快速开始

```bash
# ① 用微信开发者工具打开本目录（AppID 在 project.config.json）
# ② 云开发环境：cloudbase-d4goh1zdtc8eb9708
# ③ 部署云函数（改了 cloudfunctions/ 就要做一次）
CLI="/Applications/wechatwebdevtools.app/Contents/MacOS/cli"
$CLI cloud functions deploy --project "$(pwd)" --env cloudbase-d4goh1zdtc8eb9708 \
  --names room --paths "$(pwd)/cloudfunctions/room" --remote-npm-install true
```

**改完代码先跑测试，再部署：**

```bash
bash scripts/test-all.sh    # 9 组 / 321 项，全部离线（不启动 GUI）
bash scripts/check.sh       # 前后端一致 + 部署前检查
```

## 它长什么样

| 页面 | 说明 |
|---|---|
| `pages/lobby/lobby`（主包） | 大厅：输房间号进房 + 玩法卡（点一张就一步建好房） |
| `pages/me/me`（主包） | 昵称、音效/震动开关、关于 |
| `game/room/room`（**分包**） | 房间：entry → lobby → countdown → playing → over |

主包约 770KB、分包 660KB；`app.json` 里配了 `preloadRule`，进大厅就预下载分包。

`utils/` 里几个要认得：

| 文件 | 职责 |
|---|---|
| `games.js` | **玩法注册表的唯一事实源**（id / 人数 / 规则文案 / 图标 / 配色） |
| `feedback.js` | 音效 / 动画 / 震动的统一时间轴（每个动作定义一次） |
| `sfx.js` | 音频播放（含音量分级、静音开关） |
| `decorate` （在 room.js 里） | 派生字段的唯一出口 —— 别在别处手写 `setData({room})` |
| `poker.js` `dicerank.js` | 牌型 / 点数排名（纯函数，前后端共享） |

## 测试

**全部离线**，不需要打开开发者工具：

```bash
bash scripts/test-all.sh
```

| 组 | 覆盖 |
|---|---|
| 1 | 牌型算法（穷举 22100 手，对组合数学） |
| 2 | 游戏逻辑（转盘前后端一致、摇盅五步） |
| 3 | 多人房间（房间码 / 骰子隔离 / 房主转移 / 单人路径 / 幂等） |
| 4 | 骰盅几何（偷看时骰子真的露得出来） |
| 5 | 房间页状态机（phase→stage 唯一出口） |
| 6 | 反馈时间轴 + 错误反馈（音画同步、不许静默吞错） |
| 7 | 字段契约（图标尺寸 / 死绑定 / 幽灵字段 / 死功能 / 对比度 / 文案数字与代码一致） |
| 8 | 音效响度层级（扣盅必须压过铺垫） |
| 9 | **11 个真实场景**：五个玩法各一局，外加连玩三局、换玩法、中途退出又回来、来晚了观战、房主走了、人都走了、房间满了、换牌代价、12 人卧底、8 人比大小 |

第 9 组最值得看。它的判据不是"某个函数对不对"，而是**真实的一桌人会怎么用它**：

> 五个玩法各跑一局 · 连玩三局（跨局残留）· 换玩法再玩 · 有人退出又回来（座位空洞）
> · 有人来晚了（观战者的空骰子会让这局**永远结束不了**）· 房主走了（观战者接任会卡死）
> · 都走了（号码回收）· 房间满了（不留痕）· 换牌代价（博弈核心的数字）×12 人 / 8 人上限

**这些场景第一次、一个人、按顺序玩都不会出现** —— 而这恰好是最容易只测到的那种用法。

## 已知限制

| 限制 | 说明 |
|---|---|
| **云函数超时 3 秒** | `config.json` 里写 `timeout: 20` 云端不认（实测部署后还是 3）。只能去云开发控制台改。现在靠"启动 + 进大厅 + 进房间都发一次 ping"顶住冷启动。 |
| **音频不能进分包** | `sfx.js` 被大厅和「我的」直接使用且真的播放（进房 whoosh、开关试听 tick），而微信规则是"分包可引用主包、主包不能引用分包" —— 所以 580KB 音频只能留主包。 |
| **`gap` 需要 iOS 14.5+** | 更老的系统上间距会消失。 |
| **单人开局是测试开关** | `config.js` 的 `soloTest: true`。**正式上线前改成 false**，否则用户可以单人开始任何玩法。`check.sh` 每次会提醒。 |
